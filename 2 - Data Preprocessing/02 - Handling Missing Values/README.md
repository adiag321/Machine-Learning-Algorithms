# <p align = 'center'>Handling Missing Values</p>

In this repository I have provided the functions for different imputation techniques -

0. `Handling Missing Values in General`
1. `3M` - Mean, Median and Mode , in this technique we use these Ms for imputation
2. `CCA` - Complete case analysis, in this technique we drops the NAN values.
3. `End tail imputation` - we use statistical method to impute missing values
4. `Random-sample imputation` - here we take random sample of dame size as of our missing values
